package br.com.deployada;

import java.util.List;
import java.time.LocalDate;

public class Deployada implements Comunidade {

    private final List<Livro> estante = List.of(
        new Livro("Meu Primeiro Deploy", Formato.PDF, Formato.EPUB),
        new Livro("Git Sem Medo", Formato.PDF, Formato.EPUB),
        new Livro("Sudo Sou Eu", Formato.PDF, Formato.EPUB)
    );

    @Override
    public Release deploy(Mulher dev) {
        if (dev.temMedo()) {
            dev.respira();
            dev.lembra("você pertence a esse lugar");
        }
        return Release.builder()
            .autora("Gabriela Carvalho")
            .ambiente(Ambiente.PRODUCAO)
            .data(LocalDate.now())
            .gatekeepers(0)
            .build();
    }

    public boolean podeFazerDeployNaSexta() {
        return true; // e daí?
    }

    private void compartilhar(Livro livro) {
        estante.stream()
            .filter(Livro::gratis)
            .forEach(l -> amigas.forEach(a -> a.envia(l)));
    }

    @Scheduled(cron = "0 8 * * MON")
    public void planejarSemana() {
        agendaDePapel.abre();
        tarefas.sort(Comparator.comparing(Tarefa::prioridade));
    }

    public static void main(String[] args) {
        var gabi = new Dev("Gabi", Stack.JAVA, Stack.PYTHON, Stack.SQL);
        var pets = 6;
        try {
            new Deployada().deploy(gabi);
        } catch (SindromeDaImpostoraException e) {
            log.info("ignorado com sucesso ✨");
        } finally {
            System.out.println("girls ship it ♥");
        }
    }
}

Oi, eu sou a Gabriela Carvalho.

Trabalho com tecnologia desde 2018. Comecei como analista e dev SQL, focada em banco de dados, e depois migrei para o back-end com Java e Python. Já fui engenheira de software no Itaú e hoje sou dev back-end na Caixa Econômica Federal.

Criei a Deployada porque quase todo conteúdo de tecnologia é escrito por homens, com exemplos do cotidiano deles. Aqui eu explico os mesmos conceitos com exemplos do dia a dia das mulheres.

Também colaboro com a comunidade tech na organização do DevFest POA e do DevOpsDays POA. Fora do código, leio, toco teclado, faço dança contemporânea e artesanato. E toda semana começa do mesmo jeito: planejando tudo numa agenda de papel.

Sobre a Deployada

A Deployada é um espaço para mulheres em tecnologia aprenderem, trocarem e subirem pra produção sem pedir licença.

Todos os livros daqui são de autoria própria e ficam disponíveis de graça. Se algum te ajudou, manda pra uma amiga que está começando.
